## 1. PC에서 처리하는 정보와 목적

DoView는 사용자가 선택한 이미지·문서·압축 파일을 열고 읽기 기능을 제공합니다. 기본 보기에는 DoView 계정이 필요하지 않습니다.

- 선택한 파일의 내용·이름·경로와 메타데이터: 화면 표시, 검색, 정렬, 문서 처리에 사용합니다.
- 설정, 최근 파일과 라이브러리 정보, 읽던 위치, 책갈피·즐겨찾기, 메모·주석: 사용 환경과 읽기 기록을 복원하는 데 사용합니다.
- 표지, 압축 해제·문서 변환 임시 파일, 번역 결과와 캐시, 진단 기록: 처리 속도, 다시 보기, 문제 확인에 사용합니다. 여기에는 파일 경로와 문서 일부 또는 사용자가 작성한 글이 포함될 수 있습니다.

이 정보는 사용자의 PC에서 처리·저장됩니다. DoView는 기본 보기와 지원하는 로컬 AI 번역을 위해 원본 문서·읽기 기록·메모를 운영자의 서버로 자동 업로드하지 않습니다. 사용자가 이메일이나 공개 이슈에 직접 보내는 자료는 아래 문의 처리에 해당합니다.

## 2. 선택 기능인 로컬 AI

지원하는 별도 AI 엔진을 설치하거나 연결한 뒤, 선택한 이미지와 텍스트의 인식·번역을 PC에서 수행합니다. 이 버전은 클라우드 번역 API 키를 입력하는 기능을 제공하지 않습니다. 번역 결과는 부정확하거나 부적절할 수 있으며, 저장된 결과는 PC에 남을 수 있습니다.

엔진을 다운로드할 때는 GitHub 및 파일 전달 서비스에 접속합니다. 상대 서버는 파일 전달에 필요한 IP 주소, 요청한 주소·파일, 요청 시각, 프로그램·연결 관련 정보를 처리할 수 있습니다. 엔진 다운로드 요청에 읽는 문서나 메모를 첨부하지 않습니다. 사용자가 임의로 수정하거나 별도로 구한 엔진의 동작은 그 엔진의 제공자와 설정을 확인해야 합니다.

DoView는 외부 서비스의 접속 기록과 보관 기간을 직접 관리하지 않습니다.

## 4. 로컬 정보의 보관·삭제와 보호

포터블은 실행 파일 옆의 `Data` 폴더를, 설치형은 Windows 사용자 프로필의 앱 데이터 위치를 사용합니다. 설정과 설치 방식에 따라 위치가 달라지며, Store판은 기존 데스크톱판 프로필을 이어 쓸 수 있습니다. 임시 파일은 Windows 임시 폴더 등에 남을 수 있습니다.

읽기 기록·메모·번역 캐시는 사용자가 지우거나 앱의 캐시 정리 기능이 삭제할 때까지 남을 수 있습니다. 앱의 기록·캐시 삭제 기능을 이용하거나, 필요한 자료를 백업한 뒤 앱을 종료하고 해당 로컬 데이터를 삭제할 수 있습니다. 앱을 삭제해도 기존 데스크톱판 데이터나 사용자가 복사한 백업까지 모두 지워지는 것은 아닙니다. 원본 문서는 사용자가 관리합니다. 운영자는 사용자의 PC에 있는 자료를 원격으로 열람하거나 대신 삭제할 수 없습니다.

로컬 기록 전체를 앱 자체 암호화 저장소로 보호하는 방식은 아닙니다. PC 계정·파일 접근 권한과 디스크 보호 설정에 따라 보호 수준이 달라집니다. 공유 PC에서는 저장 기록과 백업의 접근 권한을 확인해 주세요. 다운로드에는 HTTPS와 패키지 무결성 검증을 사용합니다.

## 2. Optional local AI

After you install or connect a supported separate AI engine, recognition and translation of selected images and text run on your PC. This version does not provide cloud translation API-key settings. Translation may be inaccurate or inappropriate, and saved results can remain on your PC.

Engine downloads contact GitHub and its file delivery services. Those servers may process your IP address, requested URL or file, request time, and program or connection information needed to deliver files. ## 4. Local retention, deletion and protection

The portable edition uses a `Data` folder beside the executable; installed editions use app data in your Windows user profile. Locations depend on settings and distribution, and the Store edition may reuse an existing desktop profile. Temporary files can remain in locations such as the Windows temporary folder.

Reading records, notes and translation caches may remain until you delete them or the app's cache cleanup removes them. Use the app's history and cache controls, or back up anything you need, close the app and remove the relevant local data. Uninstalling does not necessarily remove an existing desktop profile or copies you backed up. You control your original documents. The operator cannot remotely inspect or delete data on your PC.

The app does not place all local records in an app-encrypted vault. Protection depends on your PC account, file access permissions and disk protection settings. On shared PCs, review access to saved records and backups. Downloads use HTTPS and package integrity checks.
